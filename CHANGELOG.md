# Changelog

## Unreleased

## 0.1.0 - 2026-11-23

First public release. Earlier version labels belonged to unpublished drafts.

### Added

- A corpus-focused skill with 13 analysis workflows and optional source registration.
- Shared instructions for source access, locators, linked reports, uncertainty, and evidence verification.
- Methodology notes with source links and limits on their use.
- Fictional cases for screening, apparent disagreement, and source-based draft auditing.
- Installation and usage documentation, contribution guidance, and an MIT license.
- Dependency-free repository validation and automated structural checks.

### Limits

The initial draft passed three synthetic behavioral cases. Real-paper extraction, OCR, natural triggering, large collections, and expert acceptance have not been validated. This release is an early workflow tool, not a certified research process.
